1. Engineering Context & Technical Objective

Electric distribution grids across arid, vast regions such as the Biskra territory present critical spatial challenges: dispersed medium-voltage (MV) lines, remote step-down distribution transformers, and complex feeder arrangements susceptible to thermal and sandstorm stress. When field records exist only as disconnected CAD drawings or static paper schematics, grid operators lack topological awareness.

The technical goal of this prototype was to engineer a clean, relational geometric network model from the ground up, establishing geometric and logical connectivity across all network tiers and exposing topological traversal algorithms through a lightweight WebGIS interface.

2. Prototype System Architecture

The architecture follows a strict data pipeline ensuring data integrity at every tier, from geometric validation to real-time client-side graph traversal.

3. Key Engineering Capabilities Demonstrated

Geometric Network Topology CAP-01
  • Rigorous node-to-edge topological connectivity enforcing coincidence rules
  • Hierarchical classification: 60kV Transmission → 30kV / 10kV MV Feeders → 400V LV Distribution
  • Multi-junction validation preventing disconnected orphan segments
Upstream / Downstream Tracing CAP-02
  • Instant recursive SQL Common Table Expression (CTE) graph traversal in PostGIS
  • Identification of feeding substation busbar from any downstream consumer point
  • Isolation of isolating disconnect switches to determine minimum switching boundaries
Outage & Failure Blast Radius CAP-03
  • Interactive scenario simulation: trigger a transformer fault or line rupture
  • Real-time computation of de-energized line kilometers and isolated consumer load nodes
  • Spatial bounding-hull generation for field maintenance dispatch routing
Zero-Latency WebGIS Console CAP-04
  • High-density vector tile rendering with dynamic layer filtering
  • Visual differentiation of energized vs. de-energized feeder lines in under 50ms
  • Mobile-responsive console engineered for tablet operation in field vehicles
