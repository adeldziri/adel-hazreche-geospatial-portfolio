## Deployment to GitHub Pages

This website is engineered to be **100% static**. It requires **no build step, no Node.js, no npm, and no third-party runtime frameworks**. It runs directly by opening `index.html` in any modern web browser or by pushing to GitHub.

### Step-by-Step GitHub Pages Deployment:

1. **Clone or initialize your repository:**
   ```bash
   git clone https://github.com/edwardkenway80/edwardkenway80.github.io.git
   cd edwardkenway80.github.io
   ```

2. **Copy the project files into your local repository:**
   Ensure `index.html`, `style.css`, `script.js`, `assets/`, `docs/`, and `projects/` are at the repository root.

3. **Add your PDF profile documents (optional but recommended):**
   Copy your finalized PDF files into the `docs/` directory:
   - `docs/Adel_Hazreche_One_Page_Profile.pdf`
   - `docs/Adel_Hazreche_Technical_Partnership_Profile.pdf`

4. **Commit and push to GitHub:**
   ```bash
   git add .
   git commit -m "Deploy Adel Hazreche technical portfolio"
   git push origin main
   ```

5. **Verify GitHub Pages:**
   - In GitHub, go to your repository **Settings** → **Pages**.
   - Under **Build and deployment**, ensure **Source** is set to `Deploy from a branch`, and the branch is set to `main` (or `master`) and folder to `/ (root)`.
   - Your site will be live immediately at:
     **https://edwardkenway80.github.io/**

## Technology & Engineering Principles

- **Zero-Dependency Core:** HTML5 semantic structure, CSS3 custom properties (`--var`), pure vanilla ECMAScript, and SVG vector graphics.
- **Dark Industrial Aesthetic:** Restrained technical dark palette (`#06090e`, `#0f1622`) with teal/cyan accents (`#14b8a6`, `#0ea5e9`), subtle coordinate grids, and precision hairline borders.
- **Mobile-First Responsive Testing:** Tailored for QR-code mobile scans at conferences (tested at 360px, 390px, 430px, 768px, 1024px, 1440px). Touch targets strictly $\ge 44\text{px}$.
- **Accessibility & SEO:** Semantic HTML, ARIA attributes for interactive tabs and navigation drawers, OpenGraph and Twitter card metadata, Schema.org `ProfessionalService` JSON-LD structured data.
- **Performance:** Instant first contentful paint (FCP), zero layout shifts (CLS), and zero external font or script blocking.
